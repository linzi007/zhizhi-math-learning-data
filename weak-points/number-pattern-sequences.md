## 典型表现

- `9, 26, 43, ( ), ( ), 94` 填成 `66, 89`，正确是 `60, 77`。
- `98, 83, 68, ( ), 38, ( )` 第一空 `53` 正确，最后一空写成 `25`，正确是 `23`。

## 可能原因

- `固定差未显式写出`：没有先算相邻两个数相差多少。
- `中间口算不稳`：找到规律后，后续加减仍可能算错。
- `检查习惯不足`：填完后没有反向检查最后一个数能否接回题目给出的数。

## 讲解策略

固定三步：

```text
1. 先看前两个数相差多少。
2. 再看第二个到第三个是不是同样相差。
3. 每填一个空，都用同一个差继续算。
```

例：

```text
9到26，加17。
26到43，也加17。
所以后面继续加17：60，77，94。
```

## 验证练习策略

- 每次4组即可，不要大题量。
- 每组要求在旁边写 `+几` 或 `-几`。
- 有两个空时，填完后用最后一个数检查是否能接上题目给出的数。

## 复发处理策略

- 如果只错最后一步，优先归为口算/检查问题。
- 如果连规律差都找不到，再保持为独立薄弱项。
- 如果连续两次小练4组全对，可调为 `待巩固`。
