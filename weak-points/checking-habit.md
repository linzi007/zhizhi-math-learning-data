# 薄弱项：做完检查习惯

## 当前状态

- 状态：薄弱项
- 首次发现日期：2026-05-17
- 最近证据日期：2026-05-17
- 复发次数：0
- 典型表现：做完题后没有主动检查答案；2026-05-17 同类变式卷第14-15题能按指定检查区留下检查痕迹并算对，但家长观察为“做完没有检查”。同日多步应用题小练检查了第14题，但没有发现 `50-42=18` 和答句空白，说明问题已从“有没有检查”推进到“检查是否有效”。

## 可能原因

- `检查动作未内化`：知道可以检查，但不会主动把检查当成做题的一部分。
- `答题结束感过早`：写出一个答案就认为完成，没有回到题目确认。
- `检查方法不具体`：不知道每类题该怎么检查，导致“检查”只停留在口头提醒。
- `时间压力或疲劳`：做完就想结束，跳过最后一步。

## 讲解策略

不要只说“检查一下”，改成固定动作：

```text
写完答案不算结束，还要做最后三件事：
1. 指题目：题目问什么？
2. 指答案：我答的是这个问题吗？
3. 算反过来：加法用减法查，减法用加法查。
```

对一年级先要求少而固定：

```text
每页只检查 3 题：一道加法、一道减法、一道应用题答句。
```

## 验证练习策略

- 每张卷设置 `检查3题` 区域，而不是要求整张全检查。
- 批改时记录两项：答案是否正确、是否有检查痕迹。
- 对退位减法，检查式固定为：`差 + 减数 = 被减数`。
- 对应用题，检查固定为：手指回到“答：”，看单位和问题是否一致。

## 复发处理策略

- 如果答案错且没有检查痕迹，优先判为 `检查习惯不足`。
- 如果答案对但没有检查痕迹，不扣数学理解，但记录 `检查动作未完成`。
- 连续两张卷没有检查痕迹，保持 `薄弱项`，练习卷减少题量，留出检查时间。
