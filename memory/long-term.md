# 长期记忆

## 学生档案

- 学生：芝芝
- 当前项目目标：提高数学成绩，通过薄弱项记录、练习卷、批改诊断、复评状态持续迭代。
- 学习阶段：当前为小学一年级；每年 9 月后默认进入下一年级，除非家长另行纠正。

## 年级自适应规则

- 以中国小学常见学年节奏推断：9月开学进入新年级，次年寒暑假前后仍属于该学年。
- 学期归属用于错题集和期中/期末冲刺：默认每年 9月1日 至次年 1月31日 为上学期，2月1日 至 8月31日 为下学期；如家长提供实际校历，以实际校历修正。
- 2025-2026 学年第二学期为一年级下册。
- 2026年9月起，默认按二年级上册调整题目难度、表述和知识点范围。
- 每次生成练习卷或诊断时，都要结合当前日期推断年级，并允许家长纠正。
- 题目难度要跟当前年级匹配；如果是在补旧薄弱项，可以保留低年级题型，但需说明这是巩固旧知识。

## 错题集规则

- 错题集统一放在 `mistakes/`，学校卷错题写入 `mistakes/school-mistakes.md`，系统练习错题写入 `mistakes/system-mistakes.md`。
- 每条错题必须记录 `学期` 和 `学期时间段`，例如 `一年级下学期 / 2026-02-01 至 2026-08-31`。
- 学校错题和系统错题必须区分：学校错题用于反映真实考试/周练题型，系统错题用于判断训练题是否迁移成功。
- 期中/期末冲刺时，先按当前学期筛选 `待复练`、`需确认`、`复发`、`迁移失败`，再按薄弱项生成集中复练卷。
- 已经 `已复练通过` 的错题只做少量抽查，不再作为主练。

## 教材资源规则

- 教材来源和主题索引记录在 `curriculum/textbook-sources.md` 和 `curriculum/scope.md`。
- 教材 PDF 可保存在本地忽略目录 `textbooks/primary-math-pep/`，但不提交到 Git。
- 教材用于对齐课本进度、知识点边界、题型语言和难度，不直接整页复制教材内容。
- 当前 2026-05-16 优先参考一年级下册；2026年9月起默认参考二年级上册。
- 如果用户要求巩固旧薄弱项，可以参考旧年级教材，但练习目的要标明为补旧和巩固。
- 使用教材时先查 `curriculum/scope.md`；只查看匹配的单元或页段，不每次解析整个 PDF。
- 教材索引按需扩展：先覆盖当前年级和当前薄弱项，未来用到新年级/新主题时再补索引。
- 如果需要从教材 PDF 提取文本，优先用一次性 Docker 运行 OCRmyPDF，容器结束即退出；如果 Docker 不方便，再用 Homebrew 安装 `ocrmypdf tesseract-lang`。

## 长期出题偏好

- 后续出卷默认使用低 token 工作流：先写 `worksheet-spec.json`，再用已安装 skill 中的 `skills/zhizhi-math-coach/scripts/generate_worksheet.py` 生成 `worksheet.html` 和 `answer-key.md`；聊天中只返回文件路径、题量、页数验证和目标薄弱项，不完整粘贴 HTML。
- 如果出现新的可复用题型，先在通用 skill 仓库或已安装 skill 中扩展题型参数和渲染器；不要为了单次题目把临时格式写成长期题型。
- 口算练习属于熟练度训练，题量和密度应接近学校口算卷。
- 用户提供的口算参考样张是半张 A4 约 40 题；后续口算练习卷应按约 40 题设计，而不是普通薄弱项练习的 10-14 题。
- 当芝芝大多数题能做对但做得慢时，应诊断为 `口算熟练度` 或 `提取速度` 问题，不直接判为概念不会。
- 口算训练以短频、分组、记录正确数和用时为主。
- 后续需要持续提醒：每天 5 分钟基础口算。
- 练习设计要避免把非目标能力混入数学任务；判断题优先圈选、勾选、连线，避免要求写难字拖慢练习效率。
- 练习卷优先保证字体清楚、题型有效、目标集中；不强制排满 A4，也不强制压到一页。必要时可以超过一页，避免为了卡页数浪费排版时间和 token。
- 如果某个应用题模型家长反馈“已经会了”，后续不要继续大量同构重复；改用不同情境、不同问法的小量变式题验证迁移。
- 同一组应用题不要连续使用同一场景或同一问法，除非目标就是做对比训练；默认要混合场景、混合问法，避免孩子只套题型外壳。

## 长期教学原则

- 每次练习尽量只抓一个主要薄弱点。
- 题目阅读和计算能力要分开诊断；听读后能理解的题，不直接判为数学概念不会。
- 练习卷中涉及两位数横式加减时，要提示“必须写规范竖式”。
- 练习卷中要提示“做完后自己选 1 道最容易错的题检查”。
- 批改时要记录错题类型、可能原因、证据和置信度。
- 已经 `补齐理解` 的知识点后续再错，要判断是复发、迁移失败、间隔遗忘还是偶发失误。
