# 本地记忆规则

## 目标

本项目需要同时维护长期记忆和短期记忆，避免每次重新解释芝芝的情况，也避免把临时观察误当成永久规则。

## 每次任务开始前

使用 `zhizhi-math-coach` 时，先读：

1. `memory/long-term.md`
2. `memory/short-term.md`
3. `records/learning-progress.md`
4. 相关 `weak-points/*.md`

## 长期记忆

写入 `memory/long-term.md` 的内容必须是稳定规则或长期偏好，例如：

- 学生基本情况
- 年级和学期推断规则
- 家长明确确认的练习偏好
- 长期有效的出题原则
- 不应随一次练习结果改变的项目方法

## 短期记忆

写入 `memory/short-term.md` 的内容是当前阶段观察和待办，例如：

- 最近一次卷子的表现
- 本周优先练什么
- 某个薄弱项是否刚讲过
- 最近生成但还没批改的练习
- 需要下次验证的猜测

## 短期转长期

满足任一条件，可以从短期提升为长期：

- 家长明确说“以后都这样”或指出这是长期规则。
- 同一偏好或规律连续出现 2 次以上。
- 这个规则会影响未来多次出题、批改或诊断。

## 不要写入长期记忆

- 单次错题的具体答案。
- 一次练习中的偶发失误。
- 还没有证据支持的猜测。
- 临时安排，例如“今天先做第1页”。
