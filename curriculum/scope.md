# Curriculum Scope

| Unit | Knowledge Points | Typical Practice | Notes |
| --- | --- | --- | --- |
| 认识图形（二） | 平面图形、拼组、分类 | 识别、分类、组合 | 用于图形语言和基础几何表达 |
| 20以内的退位减法 | 十几减几、退位、解决问题 | 口算、退位、简单应用题 | 当前口算慢和退位减法都应优先参考 |
| 分类与整理 | 分类、整理、统计表 | 分类标准、图表读取 | 训练“按什么标准分” |
| 100以内数的认识 | 数位、几十几、比较大小、数的顺序 | 数位意识、比较、顺序 | 与两位数加减法基础相关 |
| 认识人民币 | 元、角、分、换算、购物 | 购物应用题、单位理解 | 阅读负担高时拆句 |
| 100以内的加法和减法（一） | 两位数加减一位数、整十数、不进位/不退位、解决问题 | 横式、小竖式、应用题 | 两位数退位减法作为补弱扩展时需说明 |
| 找规律 | 图形规律、数列规律 | 观察规律、表达规律 | 先说规律再填 |
| 总复习 | 综合复习 | 阶段检测、混合练习 | 期末或阶段复测使用 |
